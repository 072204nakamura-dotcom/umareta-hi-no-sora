# 生まれた日の空

生年月日を入れると、生まれた瞬間の**実際の星の位置**から、宿曜・占星術・エドガー・ケイシーの惑星の読み方をまとめて出すページです。数秘術・干支・四柱推命などの「暦と数で読む占い」は、それぞれ別のページとして準備していきます。

**ページを開く** → https://072204nakamura-dotcom.github.io/umareta-hi-no-sora/

## できること

- **宿曜**：実際の月がいた宿（本命宿）、相性（三九の秘法）、これから7日間の日運
- **星座**：季節基準ではなく、実際の星の並びを基準にした星座（サイデリアル）
- **アセンダントと天頂**：生まれた時刻と場所から、東と南にあった星座と、その近くの天体
- **重なっている天体（合）**、**光と影（二元性）**、**サターン・リターン**
- **エドガー・ケイシー**：惑星滞在の考え方、惑星と内分泌腺の対応、魂が入るころ（受精から49日目ごろ）の配置
- **惹かれるもの・意志の欄**：配置どおりでなかった自分を書き残す場所
- **用語集**：言葉の意味をページの下で詳しく説明。難しい漢字にはふりがな付き

## 使い方

1. 生年月日を入れる（時刻と生まれた場所がわかれば、それも）
2. 「空を出す」を押す
3. 見出しの横の「？」から、言葉の説明へ飛べます

詳しくは [使い方マニュアル](manual.html) をご覧ください。

## 入力した内容について

計算はすべて、お使いの端末の中で行います。生年月日や書いた内容が、どこかに送られることはありません。書いた内容はその端末のブラウザにだけ保存されます。

## ご注意

占星術は、まだ科学では確かめられていない「未科学」の領域です。当たり外れを決めるものではなく、自分を観るきっかけとして使ってください。

## 出典・使用しているもの

- 天体の位置：[astronomy-engine](https://github.com/cosinekitty/astronomy)（MIT License）
- 星座と宿：ラヒリ式アヤナムシャ（近似）による恒星基準
- 惑星と内分泌腺の対応：日本エドガー・ケイシーセンター会長・光田秀さんの解説による
- 27宿の性格キーワード：現代の宿曜占星術で一般的に言われる傾向をまとめたもの
